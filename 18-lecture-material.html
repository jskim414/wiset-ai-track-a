18차시 · Day 3

회귀 모델 — 「부리만 보고 체중을 맞혀라」

오늘 할 일 — 딱 하나
재본 적 없는 펭귄의 체중을, 다른 측정값만으로 맞혀본다.

어제까지는 있는 데이터를 들여다봤습니다.
오늘은 없는 값을 만들어냅니다. 그게 예측입니다.

그림 3장 — 오늘의 버전
① 3자 분업 모델 만드는 건 클로드가, "이 결과를 믿어도 되나" 판단은 여러분이
② 에이전트 오늘은 회귀 에이전트를 만듭니다 — 데이터를 넣으면 예측과 해석까지 나오는
③ IPO I 부리·날개·종 → P 모델 학습·평가 → O 예측값 + 성능표 + 설명 한 단락

오늘 끝나면

  • 회귀가 무엇인지 한 문장으로 설명할 수 있습니다
  • 모델 3종을 비교하고 어느 게 나은지 근거를 댈 수 있습니다
  • RMSE·R² 를 남에게 설명할 수 있습니다
  • 어떤 변수가 중요했는지 그림으로 보여줄 수 있습니다
  • 결과를 채용 담당자가 읽을 한 단락으로 정리합니다

오늘 꼭 기억할 3가지
📏 모델은 "맞다/틀리다"가 아니라 "얼마나 빗나갔나"
🎯 복잡한 모델이 항상 좋은 건 아니다
🗣 설명할 수 없는 결과는 포트폴리오에 못 쓴다

시작하기

바탕화면 → claude-lab → my-project → 주소창 powershell → claude

outputs/ 안에 day3 폴더를 만들고,
data/processed/ 에 어제 만든 파일들이 뭐가 있는지 보여줘.

✅ 성공 신호 — 어제 만든 정제본이 보입니다. 오늘은 이걸 씁니다.

💡 어제 여러 버전을 만드셨다면 어느 걸 쓸지 지금 정하세요.
모르겠으면 → 이 파일들 중에 모델 학습에 쓰기 가장 적합한 게 뭔지, 이유와 함께 알려줘

1부 · 이론 (1시간)

A · 회귀란 무엇인가 — 한 문장

여러 값을 보고 숫자 하나를 맞히는 것.

예
부리·날개·종을 보고 → 체중을 맞힌다 오늘 할 것
날씨·요일을 보고 → 자전거 대여 수를 맞힌다 4주차
실험 조건을 보고 → 수율을 맞힌다 여러분 업무

어제와 무엇이 다른가

어제 (EDA) 오늘 (회귀)
하는 일 있는 걸 들여다본다 없는 걸 만들어낸다
결과 표·그래프 예측값 + 얼마나 정확한지
질문 "어떻게 생겼나?" "이 펭귄은 몇 g일까?"

B · 감으로 하던 걸 에이전트에게 맡긴다

여러분 업무에도 "대충 이 정도 나오겠지" 하고 감으로 잡는 숫자가 있을 겁니다.

이런 것들
"이 조건이면 수율이 얼마쯤" 실험·공정
"이만한 규모면 며칠쯤" 일정 산정
"이 정도 샘플이면 값이 이쯤" 측정·분석

감으로 하던 것을 → 데이터로 바꾸고 → 근거를 붙이는 것. 오늘 배우는 게 그겁니다.

🤔 잠깐 생각해 보세요. 내 업무에서 "감으로 잡는 숫자"는 뭐가 있나요? 카드에 적어두세요.

C · 클로드에게 회귀를 시키는 프롬프트 3종

오늘 쓸 프롬프트는 결국 이 세 가지 패턴입니다.

패턴 ① 모델 선택을 위임한다

이 데이터로 [무엇]을 예측하려고 해.
어떤 모델이 적합할지 2~3개 추천하고, 각각의 장단점을 알려줘.

💡 모델 이름을 몰라도 됩니다. 고르는 것부터 맡깁니다.

패턴 ② 결과 해석을 요청한다

이 결과가 좋은 건지 나쁜 건지,
채용 담당자에게 설명할 언어로 알려줘.

💡 숫자만 받으면 쓸모가 없습니다. 항상 "이게 무슨 뜻인지"를 함께 시킵니다.

패턴 ③ 시각화를 요청한다

이 결과를 한눈에 보여주는 그래프를 그려서
outputs/day3/ 에 저장하고, 뭘 보여주는 그림인지 설명해줘.

D · 평가지표 3개 — 이것만 알면 됩니다

지표 한 문장 좋은 쪽
RMSE 평균 몇 그램 빗나갔나 작을수록
MAE 평균 몇 그램 틀렸나 (RMSE보다 순한 버전) 작을수록
R² 체중 변동의 몇 %를 설명했나 1에 가까울수록

읽는 법

RMSE = 250g 이라면?
펭귄 평균 체중이 약 4,200g 입니다. → 약 6% 빗나갔다는 뜻입니다.

R² = 0.9 라면?
체중이 왜 다른지를 90% 설명했다는 뜻입니다.

🔴 숫자만 외우지 마세요. 항상 "무엇 대비"인지 같이 보세요.

RMSE 250g 은 펭귄(4kg)에서는 훌륭하지만, 참새 무게를 맞히는 거라면 완전 실패입니다.

모르겠으면 그냥 물어보세요

RMSE가 [숫자] 나왔어. 이게 좋은 건지 나쁜 건지
데이터의 평균이랑 비교해서 설명해줘.

2부 · 실습 「부리만 보고 체중을 맞혀라」 (3시간)

기본 과제는 실습 1~5까지.

실습 1 · 예측 문제 정의하기

코드보다 먼저 할 일입니다.

data/processed/[어제 만든 파일] 로 체중(body_mass_g)을 예측하려고 해.

1) 무엇을 맞히는 문제인지 한 문장으로 정리해줘
2) 어떤 변수를 입력으로 쓰면 좋을지 추천하고 이유를 알려줘
3) 종(species)처럼 글자로 된 변수는 어떻게 처리해야 하는지 알려줘

아직 모델은 만들지 말고, 계획만 정리해줘.

✅ 성공 신호 — 계획이 나옵니다. 아직 아무것도 안 만들어졌습니다.

🤔 글자 변수는 어떻게 숫자가 될까요? 답을 읽어보세요. 어렵지 않습니다.

실습 2 · 첫 모델 만들기

계획대로 선형회귀(Linear Regression) 모델을 만들어줘.

- 학습용과 검증용으로 나눠서 (8:2)
- 검증 데이터에서 RMSE, MAE, R²를 계산해서 보여줘
- 몇 개로 학습했고 몇 개로 검증했는지도 알려줘
- 코드는 scripts/ 에 저장해줘

✅ 성공 신호 — 지표 3개 + 학습/검증 개수가 나옵니다.

⚠️ 개수를 꼭 확인하세요. 어제 정제한 결과에 따라 달라집니다.

결과가 나오면 바로 물어보세요 (패턴 ②)

이 결과가 좋은 건지 나쁜 건지,
펭귄 체중의 평균·범위와 비교해서 설명해줘.

실습 3 · 모델 3종 비교 ⭐

같은 데이터로 아래 3가지 모델을 만들어서 성능을 비교표로 만들어줘.

1) 선형회귀 (Linear Regression)
2) 랜덤포레스트 (Random Forest)
3) XGBoost

- 같은 학습/검증 데이터를 쓸 것
- RMSE, MAE, R²를 한 표에 나란히
- 어느 모델이 가장 나은지, 왜 그런지 설명해줘

결과 표는 outputs/day3/ 에도 저장해줘.

✅ 성공 신호 — 3행짜리 비교표.

🔍 결과를 보고 놀라실 겁니다

가장 단순한 모델이 이길 수 있습니다.

왜 그럴까
데이터가 작다 (300여 개) 복잡한 모델은 배울 게 부족합니다
관계가 단순하다 날개가 길수록 무겁다 — 거의 직선입니다
복잡한 모델은 외워버린다 학습 데이터는 잘 맞히는데 새 데이터에서 틀립니다

클로드에게 물어보세요

가장 단순한 모델이 더 좋은 성능을 냈어. 왜 그럴까?
그리고 이런 경우에 어떤 모델을 골라야 하는지 알려줘.

💡 이게 오늘 가장 중요한 발견입니다.
"최신 모델을 썼습니다" 보다 "왜 이 모델을 골랐는지 설명할 수 있습니다" 가 훨씬 강합니다.

실습 4 · 예측 결과 시각화

가장 좋았던 모델의 예측 결과를 그래프로 그려줘.

1) 실제 체중 vs 예측 체중 산점도 (대각선 기준선 포함)
2) 얼마나 빗나갔는지 분포 그래프

outputs/day3/ 에 저장하고,
각 그래프가 무엇을 보여주는지 한 줄씩 설명해줘.
한글 폰트 설정해줘.

✅ 성공 신호 — 점들이 대각선 근처에 몰려 있습니다.

그림 읽는 법

보이는 것 뜻
점이 대각선에 딱 붙어 있다 잘 맞혔다
점이 위아래로 넓게 퍼져 있다 많이 빗나갔다
한쪽으로 치우쳐 있다 ⚠️ 특정 구간에서 계속 틀린다 — 문제 있음

🔍 무거운 펭귄들에서 유독 많이 빗나가지 않았나요? 그렇다면 그게 발견입니다.

실습 5 · 무엇이 중요했나 (변수 중요도)

모델이 어떤 변수를 중요하게 봤는지 순서대로 보여주고,
막대그래프로 그려서 outputs/day3/ 에 저장해줘.

그리고 1~2위 변수가 왜 중요한지,
상식적으로 말이 되는지도 판단해줘.

✅ 성공 신호 — 변수 순위 + 막대그래프.

🔴 여기서 여러분이 판단합니다

□ 1위 변수가 상식적으로 말이 되는가?
□ 어제 히트맵에서 본 것과 일치하는가?
□ 전혀 관계없어 보이는 변수가 높게 나오지 않았나?

말이 안 되면 모델이 아니라 데이터를 의심하세요.

이게 어제 배운 검증하는 감각입니다.

💡 어제 실습 7에서 "체중 예측에 쓸 변수"를 골라보셨죠. 그 예상과 맞았나요?

⚡ 심화 과제

심화 1 · 네 번째 모델

앞의 3종 외에 이 데이터에 잘 맞을 만한 모델을 하나 더 추천하고,
같은 조건으로 학습해서 비교표에 추가해줘.
왜 그 모델을 골랐는지도 설명해줘.

심화 2 · 교차검증 맛보기

지금은 데이터를 한 번만 나눠서 평가했어.
나누는 방식에 따라 결과가 얼마나 달라지는지
5-fold 교차검증으로 확인해줘.

평균 성능과 함께, 편차가 큰지 작은지도 알려줘.

💡 왜 하나요? 한 번 나눈 결과는 운일 수 있습니다. 여러 번 나눠 평균을 보면 더 믿을 만합니다.

심화 3 · 재사용 가능한 스크립트

오늘 한 작업을 처음부터 끝까지 다시 실행할 수 있는
파이썬 스크립트 하나로 정리해서 scripts/ 에 저장해줘.
주석은 한글로, 파일 경로는 맨 위에 모아줘.

💡 다음 주에 자전거 데이터로 이걸 그대로 씁니다. 잘 만들어두면 그때 편합니다.

사례집에 올릴 한 단락 ⭐

오늘 결과를 포트폴리오 언어로 바꿉니다. 모든 분이 하세요.

오늘 만든 체중 예측 모델을 채용 담당자가 읽을 한 단락으로 정리해줘.

포함할 것:
- 어떤 문제를 풀었는지
- 어떤 모델들을 비교했고 왜 이걸 골랐는지
- 성능이 어느 정도인지 (일상 언어로)
- 어떤 변수가 중요했고 그게 말이 되는지

전문용어는 최소화하고, 판단 근거가 드러나게.
outputs/day3/ 에 저장해줘.

✅ 성공 신호 — 읽어보고 내가 남에게 말할 수 있는 문장이면 성공.

⚠️ 그대로 복사해 붙이지 마세요. 읽어보고 내 말로 고치세요.
면접에서 질문받는 건 클로드가 아니라 여러분입니다.
