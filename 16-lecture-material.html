에이전트 = 목표를 주면 스스로 단계를 나눠서, 도구를 써서, 끝까지 해내는 AI

챗봇과 다른 3가지

능력 오늘 보게 될 장면
① 쪼갠다 — 큰 일을 단계로 「계획부터」 했을 때 나오는 단계 목록
② 도구를 쓴다 — 파일 열기·코드 실행 업로드 안 했는데 내 파일이 보임
③ 확인하고 고친다 — 막히면 다시 에러가 났는데 혼자 고쳐서 다시 돌림

⚠️ 진짜로 파일을 만들고 고칩니다. 답만 하는 게 아니라 실제로 손을 댑니다.
그래서 오늘 안전장치를 배웁니다.

③ IPO — 무엇을 넘기나

모든 업무는 세 토막입니다.

   ┌───────┐      ┌───────┐      ┌───────┐
   │   I   │  →   │   P   │  →   │   O   │
   │ 입력  │      │ 처리  │      │ 출력  │
   └───────┘      └───────┘      └───────┘
   무엇으로       무슨 짓을      무엇이 나와야
   시작하나        하나            끝인가

     내가          클로드가          내가
    정한다           한다           정한다

넘기는 건 P입니다. I와 O는 내가 정합니다.

예를 들면

매주 실험 엑셀 12개를 합쳐서, 조건별 평균 내고, 그래프 그린다
I 엑셀 12개
P 합치고 · 평균 내고 · 그리고 ← 클로드에게
O 그래프 1장 + 정리된 표

AI가 엉뚱한 답을 주는 이유

이렇게 말하면 무엇이 빠졌나
✗ "이 데이터 분석해줘" I도 O도 없음. 아무 파일이나 읽고, 아무 데나 저장
✓ "data/raw/penguins.csv를 열어서, 종별 평균을 표로 만들고, outputs/에 저장해줘" I·P·O 다 있음

💡 오전에 이걸 직접 두 번 돌려봅니다. 같은 데이터로 나쁜 지시문 하나, 좋은 지시문 하나.

무엇을 자동화할지 고르는 기준

입력이 매번 같은 자리에 있고, 결과물이 매번 같은 모양이면 → 자동화 1순위

🚨 2. 에러가 났을 때 — 5줄

3. 클로드에게 붙여넣는다 →

    최소 수정안과 확인 방법만 알려줘. 아직 고치지는 말고."

4. 한 번에 한 가지만 고친다.
5. 해결되면 접목 카드에 한 줄 적는다.

실습 E-2 · 일부러 에러 내보기 ⭐

에러를 만나는 연습을 지금 합니다. 진짜로 막혔을 때 당황하지 않기 위해서입니다.

data/raw/penguins.csv 에서 weight 컬럼의 평균을 내줘.

weight 라는 컬럼은 없습니다. (실제 이름은 body_mass_g)
에러가 나거나, 클로드가 "그런 컬럼이 없다"고 답할 겁니다.

이제 5줄 절차대로 해보세요. 3번 문장을 그대로 써서 물어보시면 됩니다.

💡 에러는 실패가 아니라 "어디가 문제인지 알려주는 정보"입니다.
컬럼 이름이 다른 건 실무에서 가장 자주 겪는 문제입니다. 오늘 미리 만나두는 겁니다.
그리고 오늘 해결한 에러는 3주 뒤 면접에서 쓸 소재가 됩니다.
